                              FormCut

                              Instead of CapCut

                              Download size APACHE-2.0MACOS · WINDOWS · LINUX

                              Release being prepared

                              FormCut is a complete video editor that runs entirely on your machine, with no account and no upload. A multi-track timeline, one renderer shared by preview and export, a catalogue of grades, effects and transitions, captions and subject cutout from local models, and a scripting API come in a desktop shell.                                                                         How it works

                                                                        • Start

                                                                          A project that already works

                                                                          Pick one of the twelve Form apps, pick a starter and name it. The project reads the open document and runs a command, with the SDK beside it.

                                                                        • Preview and Check

                                                                          Try it before the app

                                                                          Preview runs the extension in a simulated app, with every message between the extension and the host logged. Check reads the manifest and the code the way a host and its sandbox will.

                                                                        • Run and publish

                                                                          Into the real app, then out

                                                                          Run in App loads the extension live in the installed app. Package builds the same bytes every time, Sign adds your key, and Publish prepares the submission.

                                                                        • The form.ext registry

                                                                          Where official extensions live

                                                                          The form.ext registry is the public repository nodemode-dev/form.ext-registry, the single source of officially registered extensions for the Form apps. Each extension in it is a whole source project in its own folder. On every merge the registry builds each one into a reproducible .formpkg, signs it with the nodemode publisher key and publishes a signed index that marks it verified. FormPortal's Extensions page reads that index and installs from it. nodemode-dev/form.ext-registry

                                                                        • Submit your own

                                                                          From form.ext, or by hand

                                                                          In form.ext, Publish has Submit to Registry: it writes the extension's folder, runs the registry's own checks and opens the pull request through gh, or shows the commands to run. By hand, fork the registry, add the extension as extensions/<id>/ with its built package, its source, a README with a screenshot and a Permissions section, a CHANGELOG and a LICENSE, run python3 tools/check.py on the folder and open a pull request against main. nodemode-dev/form.ext-registry/SUBMITTING.md

                                                                        • Before it is listed

                                                                          Seven checks, then a review

                                                                          Every pull request must pass seven checks: the Form Extension Contract, a raised version for any change, a build that gives the same bytes twice, no eval, no network use except the SDK's under the network permission and the person's consent, no remote code, no obfuscation and no secrets, permissions that match exactly what the code uses, a README, a licence and a changelog, and an id and version not on the block list. An owner then reads the code, tries the extension in its app and approves it or asks for changes. An extension found breaking the rules later is blocked and turned off in every app. nodemode-dev/form.ext-registry/POLICY.md

                                                                                                        Connect to GitHub

                                                                                                        Optional. Installing, updating and everything else in FormPortal work without it. Connecting uses your own GitHub account, for sharing from Files and for your own fork of the extension registry.

                                                                                                        What happens: FormPortal shows a code, you enter it on github.com and approve. GitHub is asked only to let FormPortal read your public profile (the read:user permission), to show who is connected. GitHub gives FormPortal a token, which is kept in this computer's keychain and nowhere else. Nothing goes to formai.studio or anyone else: FormPortal talks only to github.com and api.github.com, and only when you use sharing or the fork below.

                                                                                                        Disconnect removes the token from this computer's keychain. To withdraw FormPortal's access on GitHub as well, revoke FormPortal under Settings, Applications, Authorized OAuth Apps on github.com. Open GitHub's application settings

                                                                                                        Extension registry fork

                                                                                                        Optional. Makes your own copy (a fork) of nodemode-dev/form.ext-registry, the public registry of Form extensions, in your GitHub account, so you can submit an extension of your own.

                                                                                                        If you continue, FormPortal asks GitHub to fork nodemode-dev/form.ext-registry into your GitHub account. The fork is a public repository in your name, which you can delete on github.com at any time. Forking needs GitHub's public_repo permission, which lets FormPortal create and change public repositories in your account; FormPortal uses it only to make this fork. Nothing else is created, changed or sent.

                                                                                                        GitHub has not given FormPortal that permission yet: approve it first with a new code, then fork.

                                                                                                        Forking on GitHub...

                                                                                                        Your fork is ready:

                                                                                                        1. With form.ext: its Publish step has Submit to Registry, which writes extensions/<id>/ into a folder you choose, runs the registry's checks and shows the git and gh commands that open the pull request.
                                                                                                        2. By hand: clone your fork and add your extension as extensions/<id>/, where <id> is the id in its manifest, with its package, source, package.json, package-lock.json, README.md, CHANGELOG.md, LICENSE and a screenshot.
                                                                                                        3. Run python3 tools/check.py extensions/<id> and fix every error it prints.
                                                                                                        4. Commit on a branch, push it to your fork and open a pull request against main. Say what the extension does and why it asks for each permission.
                                                                                                        5. The owners review it; on merge it is built, signed and listed in FormPortal at its next index refresh.
